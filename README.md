# 📊 Power BI Dashboard — Indústria Farmacêutica

Dashboard desenvolvido em **Power BI** para análise de vendas, produtos, distribuidores, fábricas e performance regional de uma indústria farmacêutica.

O projeto tem como objetivo transformar dados comerciais e operacionais em informações visuais para apoiar a tomada de decisão e o acompanhamento de indicadores de negócio.

---

## 🎯 Objetivo do Projeto

Desenvolver uma solução de Business Intelligence capaz de apresentar uma visão integrada da operação comercial da indústria farmacêutica, permitindo acompanhar:

* Evolução das vendas
* Faturamento
* Performance de produtos
* Distribuição regional
* Desempenho de distribuidores
* Performance das fábricas
* Indicadores operacionais
* Classificação e participação dos produtos

---

## 📌 Estrutura do Dashboard

### 1. Visão Executiva

Apresenta uma visão geral da performance do negócio, permitindo identificar rapidamente os principais indicadores e tendências.


### 2. Performance de Produtos

Análise da performance dos produtos comercializados, permitindo identificar produtos de maior relevância para o faturamento e participação no negócio.


### 3. Performance Operacional

Análise da operação considerando distribuidores, fábricas e demais indicadores relacionados à performance operacional.
